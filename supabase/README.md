# Deploying the Co-pet backend

1. `supabase link --project-ref <ref>`
2. `supabase db push`
3. `supabase secrets set NOTION_CLIENT_ID=… NOTION_CLIENT_SECRET=… ASANA_CLIENT_ID=… ASANA_CLIENT_SECRET=… COPET_SERVICE_KEY=<secret key from Project Settings › API keys> COPET_OAUTH_DONE_URL=https://mrdeeds88.github.io/oauth/done/`. The done page is a static HTML page (here GitHub Pages, repo `mrdeeds88.github.io`, file `oauth/done/index.html`) that sets `location.href = "copet://oauth/done?" + location.hash.slice(1)` and shows an "Open Co-pet" link. It can't be served by an Edge Function: hosted functions rewrite GET `text/html` to `text/plain`.
4. `supabase functions deploy oauth --no-verify-jwt`
5. Set the Notion public integration redirect URI and the Asana app redirect URL to `https://<ref>.supabase.co/functions/v1/oauth/callback`.
6. Register these scopes on the Asana app: `tasks:read tasks:write workspaces:read projects:read attachments:write users:read`. On the Notion public integration (Configuration › Capabilities), enable Read content, Update content and Insert content.
7. Build the app with `COPET_SUPABASE_URL=https://<ref>.supabase.co` and `COPET_SUPABASE_KEY=<publishable key>`.
8. `supabase functions deploy delete-account` (JWT verified by the gateway).
9. Dashboard › Authentication › Providers › Email: enabled, "Confirm email" on, email OTP length 6, OTP expiry 600 s.
10. Dashboard › Authentication › Emails › SMTP Settings: a custom SMTP server. Free projects can't edit email templates on the built-in mailer, which also sends only 2 emails an hour. Use Resend: host `smtp.resend.com`, port `465`, user `resend`, password the Resend API key, sender `Co-pet <no-reply@<domain>>`. Then Authentication › Rate Limits › emails per hour `30`.
11. Dashboard › Authentication › Email templates › "Magic Link" and "Confirm signup": subject "Your Co-pet sign-in code", body from `templates/sign_in_code.html` (it contains `{{ .Token }}`). `/otp` sends "Confirm signup" to a new user and "Magic Link" to an existing one; a template with `{{ .ConfirmationURL }}` sends a link that ends on the Site URL.
12. Dashboard › Authentication › Providers › Google: enabled with a Google Cloud OAuth client (type Web application, authorized redirect URI `https://<ref>.supabase.co/auth/v1/callback`).
13. Dashboard › Authentication › URL Configuration › Redirect URLs: add `copet://auth/callback`. Without it, Supabase drops the app's `redirect_to` and sends the browser to the Site URL.
14. Dashboard › Authentication › URL Configuration › Site URL: `https://mrdeeds88.github.io/copet/`.
15. **Google, owner.** In Google Cloud project `co-pet-prod`, Google Auth Platform:
    1. Audience: External, Published. Branding: app name "Co-pet", logo `src-tauri/icons/128x128@2x.png`, support email, homepage `https://mrdeeds88.github.io/copet/`, privacy `https://mrdeeds88.github.io/copet/privacy/`, terms `https://mrdeeds88.github.io/copet/terms/`. Authorized domains: `mrdeeds88.github.io` and `supabase.co`. Scopes: `openid`, `.../auth/userinfo.email`, `.../auth/userinfo.profile` only. These are non-sensitive, so brand verification is the only review (https://developers.google.com/identity/verification/authentication-verification).
    2. Click Verify Branding, then Publish branding.
16. **Notion, owner.** The public connection must have installation scope **Any workspace**. The scope is set at creation and can't be changed (https://developers.notion.com/guides/get-started/public-connections). If the existing one is "Selected workspaces only", create a new one with the same redirect URI and capabilities (steps 5 and 6) and run `supabase secrets set NOTION_CLIENT_ID=… NOTION_CLIENT_SECRET=…`. Fill the listing fields with the site URLs: `https://mrdeeds88.github.io/copet/`, `https://mrdeeds88.github.io/copet/privacy/`, `https://mrdeeds88.github.io/copet/terms/`, `https://mrdeeds88.github.io/copet/support/`. No Marketplace listing.
17. **Asana, owner.** Developer console › Manage distribution › **Any workspace**. App listing details: icon, name "Co-pet", descriptions, company URL and landing page `https://mrdeeds88.github.io/copet/`, support URL `https://mrdeeds88.github.io/copet/support/`, privacy URL `https://mrdeeds88.github.io/copet/privacy/` (https://developers.asana.com/docs/share-your-app). No App Directory submission.
